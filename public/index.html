For developers
The app, importable library, CLI and MCP server use the same verification engine. From the REGRA folder:
node src/cli.mjs demo

node src/cli.mjs verify \
  --case examples/average.case.json \
  --before examples/average.before.js \
  --after examples/average.fixed.js

node src/cli.mjs check \
  --case examples/average.case.json \
  --source examples/average.fixed.js

node src/cli.mjs context --project demo-analytics
Backslashes above split a command in Bash. On Windows, enter each command on one line. Exit code 0 means passed; 1 means rejected or inconclusive; 2 means a setup error.
Use it with a coding assistant
Open Connections for setup commands for Cursor, Claude Code, Codex or VS Code. Agents can retrieve lessons, verify changes, and inspect proof through MCP. Agents without MCP can use the CLI or context export.
How it stays free to run
No account, service subscription, or paid API is required. The app and MCP server run on your computer. Your connected agent supplies its own model; optional dashboard suggestions use local Ollama. Install the package dependencies once.
What a green result means
The recorded cases passed on this code, under this runtime. Three repeat runs can reveal some unstable tests; they cannot prove a program has no bugs. Expected behavior needs human review.
Current boundaries
v0.2 handles reviewed, self-contained synchronous JavaScript functions. It is not a sandbox for hostile code. Whole-repository execution, Python, browser tests, and shared team libraries remain future work. MCP does not automatically require an agent to call REGRA.
